# Квіз «Хто така Марія Брицька?»

Без реєстрації й акаунтів. Гравці заходять за QR-кодом, вводять ім'я й одразу з'являються на екрані ведучого.

## Запуск на компʼютері
    node server.js
Ведучий: http://localhost:3000/host?key=masha

## Щоб друзі зайшли з телефонів, треба розмістити в інтернеті
Підійде будь-який хостинг для Node.js (Render, Railway, Fly.io, Glitch). Приклад для Render:
1. Завантаж папку на GitHub.
2. render.com → New → Web Service → обери репозиторій.
3. Build Command: порожньо. Start Command: `node server.js`.
4. У Environment додай `HOST_KEY` (твій пароль ведучого).
5. Відкрий `https://<твій-сайт>.onrender.com/host?key=<HOST_KEY>`. QR-код на екрані ведучого вже вестиме на правильну адресу.

Без `HOST_KEY` ключ ведучого за замовчуванням `masha`, тому на справжньому сайті обовʼязково задай свій.
